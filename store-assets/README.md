# Monstera — store upload kit

Prepared for version 1.3.0, Pebble Time 2 / Emery, English.

| File | Purpose |
| --- | --- |
| `Monstera Watchface.pbw` | Release binary |
| `description.txt` | Paste-ready full description, under 1,600 characters |
| `listing-info.json` | Title, short description, project links, and asset filenames |
| `monstera-screenshot-emery.png` | Actual unframed emulator screenshot, 200 × 228 |
| `monstera-banner-720x320.png` | Optional promotional banner, 720 × 320 |
| `monstera-icon-144.png` | Large reusable promotional icon, 144 × 144 |
| `monstera-icon-80.png` | Small reusable promotional icon, 80 × 80 |

Create a **watchface** listing titled **Monstera** and use the **Emery** asset collection. Upload the PBW, paste the description, and add the screenshot and optional banner. The icons are provided for reuse; watchface listings do not require app icons. Leave the support email field blank to use the developer account's email, or enter your preferred address. No separate Android/iOS companion listing is needed.

The screenshot is a direct capture from the release build and intentionally shows dashes for unavailable heart-rate data. The banner and icons are promotional illustrations created with the built-in imagegen tool, not simulated screenshots. Masters and prompts are retained under `artwork/store/` in the repository.

This kit prepares the assets only; no app-store listing has been created or published.

Official guidance:
- [Preparing a submission](https://developer.rebble.io/guides/appstore-publishing/preparing-a-submission/)
- [Publishing a watchface and required resources](https://developer.rebble.io/guides/appstore-publishing/publishing-an-app/)
- [Asset guidance: listing screenshots must be unframed](https://developer.rebble.io/guides/appstore-publishing/appstore-assets/)
